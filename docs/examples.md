# Эталонные экраны

Каждый экран ниже собран рендерером из спеки, без ручной правки. Спеку можно открыть, поменять и пересобрать:
`node scripts/build-call.mjs <спека> --section "Polygon · <имя>"`.

| Экран | Спека | Что показывает |
|---|---|---|
| Профиль | `specs/examples/profile.json` | Объект — человек: герой с фото, личные данные, безопасность с тумблером Face ID, настройки приложения, нижний чат |
| Уведомления | `specs/examples/notifications.json` | Список настроек: тумблеры применяются сразу, подписи говорят, что именно придёт |
| USD-счёт | `specs/examples/account-usd.json` | Объект — счёт: баланс-герой, пара действий, кошельки в сумме дают баланс, транзакции |
| Перевод · подтверждение | `specs/examples/send-confirm.json` | Откуда → куда, сумма, стоимость и баланс после, одна Primary |
| Перевод · выбор счёта | `specs/examples/send-confirm.json` | Шит с выбором и последствиями поверх затемнённого экрана |
| Заморозка карты C1–C4 | `scenarios/freeze-card.json` | Кликабельный флоу: заморозка без подтверждения, Alert только перед блокировкой, новая карта, возврат на объект |
| Чат · один факт | `specs/examples/chat-salary.json` | Lead: ответ белым, следующий шаг серым |
| Чат · цифры | `specs/examples/chat-food-october.json` | Lead + ряд чисел + смысл одной фразой + источник; характер analyst |
| Чат · перевод в цель | `specs/examples/chat-spain-topup.json` | Check перед переводом и ровно три чипа; тот же ответ в характере caregiver; ответ после действия с Undo |

Скриншоты добавляются после прогона `run-evals` (секция `Polygon · evals` в Figma).
