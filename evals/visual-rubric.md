# Visual rubric (for screen-critic)

Score 1–10. Ship when every score is ≥ 8. Weight: Cohesion and Fullness count double in the average.

| Criterion | 10 looks like | 5 looks like |
|---|---|---|
| Cohesion | One obvious hierarchy: the eye goes hero → actions → sections. The hero is the heaviest thing on screen. | Order is right but the hero is weak; the eye drops into a list |
| Fullness | Dense like the product: every section 2–5 informative rows, captions carry facts, no dead bands | Long screen of thin settings, dead zones, one-row sections, empty captions |
| Character | Feels like re:verse next to the references: mono captions, two-tone where allowed, grey icon plates, pill actions, bottom chat, product words | Generic template; kit parts used but no product object or voice |
| Craft | Left edges on 16, measured spacing (48 / 24 / 20 / 12), one icon family, no truncation, type scale per layout.md | Mixed icon styles, truncated labels, overlaps, uneven gaps |
| Product sense | Right sections for the object, real data from persona.md, states shown as rows, nothing invented, hard rules kept | Odd or invented copy, misplaced actions, Spirit named in base UI |
