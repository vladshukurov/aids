# Как менять систему

Для тех, кто отвечает за дизайн-систему: компоненты, правила, рендерер.

## Где что живёт (один факт — одно место)
| Что | Файл | Кто читает |
|---|---|---|
| Жёсткие правила и пайплайн | `AGENTS.md` (Claude читает его через `CLAUDE.md`) | все агенты |
| Все числа отступов | `foundations/layout.md` §3 | агенты, рендерер (`gapBase` в `scripts/figma/render.js`) |
| Данные персонажа | `foundations/persona.md` | агенты, линтер |
| Свойства компонентов | `state/library.json`, `components/_properties.md` — **генерируются** | рендерер, `check-docs` |
| Когда брать компонент | `components/*.md` | агенты |
| Рецепты экранов | `recipes/*.md` + эталонные спеки `specs/examples/*.json` | агенты, evals |
| Правила, проверяемые кодом | `scripts/lib/spec.mjs` (линтер), `scripts/figma/audit-screen.js` | агенты |
| Скиллы | `.agents/skills/` → копия в `.claude/skills/` (`node scripts/sync-agents.mjs`) | Codex, Claude |
| Критики | `agents/` → копия в `.claude/agents/` | Codex, Claude |

## Изменили компонент в Figma
1. Опубликуйте библиотеку: Assets → Publish.
2. Запустите скилл `sync-library`: он обновит `state/library.json`, `components/_properties.md` и список иконок.
3. `npm run check`: покажет md-файлы, где упомянуты свойства или значения, которых больше нет.
4. Если поменялись свойства, которые выставляет рендерер, поправьте `scripts/figma/render.js`.
5. Запустите скилл `run-evals` и сравните с прошлым прогоном в `evals/runs/`.

## Изменили правило
1. Найдите единственное место, где оно живёт (таблица выше), и правьте только там. В остальных файлах должна быть ссылка, а не копия.
2. Если правило можно проверить кодом, добавьте проверку в линтер или аудит.
3. `npm run lint && npm run check`, затем `run-evals`.
4. Запишите изменение в `CHANGELOG.md`.

## Изменили рендерер
1. Правка в `scripts/figma/render.js`.
2. `node scripts/build-call.mjs <любая спека> --patch-from <хеш из state/renderer.installed.txt>` создаёт `.out/patch.js` размером 1–3 тысячи символов. Запустите его одним вызовом `use_figma`. Если копии старой версии нет, запускайте `.out/install.js`: это полная установка, около 37 тысяч символов.
3. Скопируйте `.out/renderer-<новый хеш>.txt` в `state/renderer.installed.txt` (первая строка — хеш) и закоммитьте: так следующий человек сможет сделать патч.
4. Пересоберите эталонные спеки (`--replace`) и сравните скриншоты.

## Добавили тип экрана
Рецепт `recipes/<name>.md`, эталонная спека `specs/examples/<name>.json`, строка в `recipes/overview.md` и промпт в `evals/prompts.md`. Если нужен новый блок, сначала соберите компонент в Figma (раздел Blocks), затем научите рендерер его ставить.

## Перед мерджем
```bash
npm run lint      # все эталонные спеки проходят линтер
npm run check     # доки, Figma и копии скиллов согласованы
```
Изменения правил, рендерера или компонентов дополнительно проверяются скиллом `run-evals`.
