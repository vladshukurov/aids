# Typography

Use text styles. Never set font, size or line height by hand. Families come from Theme (`font/text`, `font/mono`).

## Base UI
| Style | Size/line | Use |
|---|---|---|
| Large Title | 34/36 Medium | Rare: big screen titles in onboarding |
| Title/Title 1 | 32/36 Medium | Hero sentence, balance |
| Title/Title 2 | 24/28 Medium | Section hero, amount in a sheet |
| Title/Title 3 | 20/24 Medium | Card titles, empty-state titles |
| Title/Title 4 | 18/22 Medium | Small headings |
| Title/Display 1–3 | 96 / 64 / 36 Medium | Amount entry, big numbers |
| Body/Large | 17/26 Regular | Long paragraphs, steps |
| Body/Regular | 16/20 Regular | Default text |
| Body/Medium | 16/20 Medium | Cell titles, emphasis |
| Body/Small | 14/18 Regular | Secondary text |
| Caption/Regular | 14/18 Mono | Row captions, metadata |
| Caption/Small | 12/16 Mono | Labels, footnotes |
| Caption/Small sentence | 12/16 Mono | Consent, legal (no uppercase) |
| Control/Button/Regular, Small | 16/24, 14/18 Mono | Button labels (inside Button only) |
| Control/Input/Regular, Label | 16/20, 12/14 | Inside Text Field / Select only |
| Control/Chip | 14/18 Medium | Inside Chip / Suggest only |
| Section/Title | 17/22 Medium | Section title on new screens, sentence case, `text/primary` |
| Section/Aside | 15/20 Regular | Right side of a section header (total, "View all"), `text/secondary` |
| Label/Hero | 15/20 Medium | Label above a hero number ("October · 12 days left"), `text/secondary`, no caps |

## Chat (dark)
| Style | Use |
|---|---|
| Chat/Lead 32/36 | First sentence of an answer: white answers, grey continues |
| Chat/Metric 64/70 | One hero number (balance, transfer sum) |
| Chat/H2 24/28, Chat/H3 20/24 | Sections of a long answer |
| Chat/Body 17/26, Chat/Body strong | Paragraphs, bold key phrase |
| Chat/Small 15/22 | Secondary paragraph |
| Chat/Numeric 15/20 Mono | Numbers in tables |
| Chat/Label 12/16 Mono caps | Label above a number, Meta, table head |

## Rules
- Brand: "re:verse", lowercase, also in uppercase labels.
- No full stop at the end of chat sentences, list items and captions.
- Keep names, "amount + word" and dates on one line: Anna Costa, €40 a month, 26 Oct.
