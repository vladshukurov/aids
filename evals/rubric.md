# Rubric: one screen

Score each line 0 / 1 / 2. A screen passes at 16+ of 20 with no zero in the first four.

| # | Check | 2 | 1 | 0 |
|---|---|---|---|---|
| 1 | Built from the system | Only instances + auto-layout wrappers | 1–2 hand-drawn bits | Hand-drawn components |
| 2 | Tokens | Audit: 0 raw fills, 0 unstyled text | ≤ 3 issues | More |
| 3 | Product rules | All hard rules in CLAUDE.md kept | 1 slip | Success screen, two Primaries, green outflow, "Spirit" in base UI |
| 4 | Right recipe | Structure matches the recipe | Minor order change | Wrong pattern |
| 5 | Data | Real names, numbers add up | One mismatch | Placeholders |
| 6 | Copy | Short, product words, ToV | Slightly long | Generic or wrong tone |
| 7 | Layout | Aligned, 16 margins, consistent gaps | Small drift | Overlaps, clipping |
| 8 | Modes | Correct light/dark and Theme | — | Wrong mode |
| 9 | States | Asked-for state is shown (frozen, error, empty) | Partly | Missing |
| 10 | Report | Says recipe, components, audit result, gaps | Partial | None |

Human review on top: visual quality and brand character. The agent does not grade those.
