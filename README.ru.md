# re:verse DS — AI-ready дизайн-система

Демо-пакет Pragmatica: дизайн-система, на которой Claude собирает экраны в Figma по тексту или брифу.
Основа — кит и паттерны продукта re:verse, сверху — слой тем (цвета, скругления), чтобы показать смену бренда.

## Из чего состоит
| Слой | Где | Зачем |
|---|---|---|
| Figma-файл | `qUknPCIey4DG3PH19e1OmD` | Токены, компоненты с описаниями, эталонные экраны (Examples), полигон |
| `CLAUDE.md` | корень | Жёсткие правила и порядок работы агента |
| `llms.txt` | корень | Индекс: что читать под задачу |
| `foundations/` | | Токены, темы, типографика, тон |
| `components/` | | По файлу на компонент: когда брать, свойства, правильно/неправильно |
| `recipes/` | | Рецепты экранов: состав, порядок, правила |
| `scenarios/` | | Флоу из брифа: шаги, экраны, крайние случаи |
| `.claude/skills/` | | build-screen, build-flow, audit-screen |
| `evals/` | | Типовые запросы клиентов и рубрика оценки |
| `state/` | | Реестр id из Figma для агентов |

## Как показать
1. Открыть Figma-файл, страницу Polygon.
2. В Claude Code в этой папке: «Собери экран перевода другу» или `/build-flow` с брифом.
3. Смена бренда: выбрать фрейм → Theme → другой режим.

План работ и статус: `PLAN.md`.
