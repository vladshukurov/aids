# Продуктовый фильм re:verse DS — сценарий

**Идея:** у фильма одна нить — строка запроса. Человек пишет обычную фразу, система отвечает готовым интерфейсом, и каждая новая сцена начинается с новой фразы. Титров нет, всё рассказывает сам интерфейс.

**Формат:** 16:9, 1920×1080, 30 fps, 58 секунд, без звука. Светлый фон, белые карточки, мягкие тени, спокойные движения. Файл: `docs/video/film.mp4`. Рендер: `scripts/video/film.py`.

| Время | Сцена | Что видит зритель |
|---|---|---|
| 0–4.6 | **1. Вопрос** | Пустой светлый экран. В центре появляется строка запроса и печатается «Собери экран профиля». Нажатие на отправку, строка уходит вниз и становится постоянной панелью ввода |
| 4.6–13.5 | **2. Думает и собирает** | Слева над карточкой висит отправленная фраза, а под ней агент рассуждает: правила → рецепт → план → данные → спека и линтер (каждый шаг: спиннер, затем галочка). Справа экран профиля собирается блок за блоком: шапка, герой, секции, нижний чат. Потом экран плавно прокручивается до конца |
| 13.5–25 | **3. Флоу** | Новый запрос «Флоу: я потерял карту». Справа въезжают четыре экрана, и флоу проигрывается как прототип: тап «I lost my card» → алерт «Block this card?» → тап «Block card» → заказ новой карты → тап «Order new card» → карта заблокирована, новая в пути |
| 25–32 | **4. Бренд** | Запрос «Сделай то же в бренде Atlas». Карта и профиль стоят рядом, через оба экрана проходит линия, и за ней интерфейс меняется на Atlas: синие кнопки, другие скругления, другой шрифт. Вёрстка остаётся той же |
| 32–47.5 | **5. Ассистент** | Запрос «Сколько я потратил на еду в октябре?». Тёмный чат собирает ответ по частям: вопрос, лид, цифры, вывод, источник, подсказки. Следующий запрос «Переведи €100 в цель Spain trip» даёт проверку перед переводом. Переключатель характера проходит neutral → analyst → trickster → caregiver: свечение и фраза меняются, цифры остаются. Тап «Top up €100» — «Moved» и Undo вместо экрана успеха |
| 47.5–58 | **6. Библиотека** | Экран отлетает назад и становится частью бесконечной наклонной галереи: профиль, цель, транзакции, карты, чаты. Строка ввода остаётся впереди с мигающим курсором и подсказкой «Что собрать дальше?» |

## Что показывает каждая сцена
1. Входная точка — обычная фраза на русском, без технических команд.
2. Агент работает по системе: правила, рецепт, данные, линтер. Экран собирается из компонентов библиотеки, а не рисуется.
3. Из того же процесса получаются флоу с переходами, а не только отдельные экраны.
4. Тема — один переключатель: бренд меняется без перерисовки.
5. Ассистент — часть системы: ответы собираются из тех же частей, характер переключается одной переменной, денежные действия проходят проверку и Undo.
6. Всё вместе — живая библиотека экранов, которая растёт с каждым запросом.

## Экраны в кадре
Profile, Profile · Atlas, C1–C4 (заморозка карты), C1 · Atlas, Chat · numbers (сборка из пустого чата), Chat · money check в четырёх характерах, Chat · after the top-up, Spain trip, Transactions, USD account, Notifications, Send · confirm и pay from. Все экраны собраны рендерером из спек (`specs/examples/`, `scenarios/freeze-card.json`).
